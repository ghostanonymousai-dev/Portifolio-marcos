## 🚀 Deploy

### Vercel (Recomendado)
```bash
# Clone este repositório
git clone https://github.com/seu-usuario/portfolio-marcos.git

# Vá para a pasta
cd portfolio-marcos

# Push para GitHub
git push origin main

# Conecte no Vercel
# Dashboard → Add New → Import from Git → Selecione este repo
```

Seu site ficará em: `https://portfolio-marcos.vercel.app`

### GitHub Pages
```bash
git push origin main
# Settings → Pages → Deploy from branch: main
```

Seu site ficará em: `https://seu-usuario.github.io/portfolio-marcos`

## 🎨 Personalizações

### Mudar Cores
Edite `index.html` na seção `<style>`:
```css
:root {
  --primary: #06b6d4;      /* Azul claro */
  --secondary: #0ea5e9;    /* Azul */
  --tertiary: #a855f7;     /* Roxo */
}
```

### Adicionar Seu Vídeo
Substitua o ID do YouTube:
```html
<!-- Antes -->
src="https://www.youtube.com/embed/dQw4w9WgXcQ"

<!-- Depois (seu vídeo) -->
src="https://www.youtube.com/embed/SEU_ID_AQUI"
```

### Adicionar Projetos
Copie e customize um bloco `<div class="project-card">` na seção Portfolio.

### Adicionar Depoimentos
Copie e customize um bloco `<div class="testimonial-card">` na seção Depoimentos.
